# Расписание группы П-308 (СтГМУ · Педиатрический факультет)

Расписание учебных занятий 3-го курса (5-й семестр, сентябрь — декабрь 2026) с автоматическим расчётом учебной недели, чётности (`1-я` / `2-я` неделя), точных дат лекций, преподавателей, корпусов и текущей пары.

- **Дизайн**: Графит + Песчаный + матовое стекло (`Glassmorphism`) с внутренним свечением и аккуратным градиентным фоном (+ переключение тёмной/светлой темы).
- **Офлайн Android APK + Веб-версия**: единый самодостаточный интерфейс без внешних запросов, локальная PIN-защищённая админ-панель (`⚙ Админ`), звонки (`🔔 Звонки`) и справочник адресов корпусов (`🏛 Корпуса`).

## Как загрузить в свой GitHub, чтобы APK и сайт собрались сами

1. Создайте новый открытый (**Public**) репозиторий на GitHub (например, `Schedule_P308`).
2. Загрузите туда все файлы этого проекта (включая скрытую папку `.github/workflows/build-apk.yml` — проще всего через `git push` или распаковав архив).
3. Перейдите во вкладку **Actions** — сборка запустится автоматически и через ~1.5 минуты готовый **`P308.apk`** появится в разделе **Releases** справа на главной странице репозитория (а также внутри запуска Actions в блоке **Artifacts**).
4. Чтобы включить **веб-версию** (`github.io`): откройте в репозитории **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/(root)` → Save**. Через минуту сайт будет доступен по ссылке `https://<ваш_логин>.github.io/<имя_репозитория>/`.
5. Для выпуска обновлений с уведомлением внутри приложения создайте новый тег/релиз (например `v1.1`, `v1.2`).
